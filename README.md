# Ну, с возвращением!

**[Скачать игру из Releases](https://github.com/NMGorovenko/Wellcumback/releases/latest)** · Изменения версии **0.3.0**: [заметки выпуска](docs/releases/v0.3.0.md)

Подарочный сборник для Ромы, которого Ярослав и Никита ждут из армии. Две трёхмерные истории можно выбирать отдельно или проходить друг за другом; результаты складываются в счёт вечера. Режимы: один, два или три игрока за одним экраном. В соло экран собирают Никита и Ярик; казарму Рома убирает один. Поддерживаются клавиатура, стандартные геймпады и смешанное управление.

**«Экран на полстены».** Квартира по фотографиям: собрать рамку, вставить спицы в отдельное полотно, натянуть пружины общей отвёрткой, просверлить два отверстия со стульев и совместить экран с крючками. Никита стоит на полу, страхует и подаёт; Ярик забирается, по очереди принимает дрель и пылесос и работает ими одновременно. Кирпичная пыль остаётся на белой стене, если забыть пылесос. После падения Ярик возвращается на пол, снова забирается и получает оба инструмента. Готовые отверстия сохраняются.

**«Операция “Чистый проход”».** Сначала игра за безымянного солдата другой роты: дежурство, дневальный с крепкими репликами, происшествие, туалет, душ и загрузка брюк в стиралку. Затем на уборку выходит Рома, при двух игроках добавляется Никита, при трёх — Ярик. В одиночку убирает только Рома. Пять помещений отделены от плиточного коридора; деревянная тумба, красная накладка, телефон и стенды опираются на фото российской казармы. Рома не изображает виновника происшествия.

Визуальное направление — эпоха PS3: узнаваемые фото лиц на объёмных формах, процедурная мебель и выразительные анимации. Внизу кадра первой истории показаны короткие подсказки Никите и Ярику: что нажать, держать или отпустить сейчас. В обеих играх есть выбор эпизода: новая тренировочная попытка начинается с нужного места, остаётся с нулевыми очками и не меняет счёт вечера. Фото красного Mustang сохранены для будущей истории, автомобильного геймплея пока нет.

## Где лежит проект

Текущая рабочая папка: `/Users/nikitagorovenko/Documents/ChatGPT/Wellcum back`.

- `lib/game/` — правила, ввод и звук.
- `components/game/` — сцены, персонажи, предметы и HUD.
- `hooks/` — цикл игры, пауза, геймпады и хранение результатов.
- `public/` — ресурсы, которые загружает браузер.
- `references/` — неизменённые фото и исходный рассказ.
- `docs/` — сценарии и техническая документация.
- `tests/` — проверки правил, управления и геометрии.

## Отправить другу файл для игры

Самостоятельная версия собирается командой `npm run build:portable`. Результат: `outputs/portable/Wellcum-back.html`. В нём находятся обе игры, стили, лица и текстуры; сервер, Node.js и аккаунт ChatGPT для игры не нужны. Отправлять можно этот HTML или ZIP с HTML и `README.txt`. Друг скачивает файл и открывает его в обычном настольном браузере, а не в предпросмотре мессенджера.

Офлайн-сборка использует тот же `app/page.tsx` и игровые модули, без копирования механик. `portable/entry.tsx` монтирует игру, `scripts/build-portable.mjs` собирает один обычный скрипт и встраивает ресурсы. Политика содержимого запрещает сетевые соединения. Результаты сохраняются, если браузер разрешает хранилище для локального файла; иначе работают до закрытия вкладки. Формат остаётся переносимым HTML, без EXE-приложения и сетевого кооператива: участники играют за одним компьютером.

Проверка самостоятельной сборки включает сборку HTML, синтаксис, отсутствие внешних импортов и целостность встроенных ресурсов. Открытие скачанного файла через `file://`, звук, устройства и браузерный маршрут проверяются отдельно. Фактические результаты для 0.3.0 должны быть внесены в [заметки выпуска](docs/releases/v0.3.0.md) перед публикацией.

## Запуск на macOS / Windows

Нужен Node.js 22.13 или новее; для разработки и тестов удобно использовать Node.js 24. Команды выполняются из папки проекта:

```sh
npm ci
npm run dev -- --port 3001
```

Открыть [localhost:3001](http://localhost:3001/). Если порт занят, посмотреть фактический адрес в выводе сервера. Первая установка зависимостей требует интернет. Игровые изображения хранятся в проекте; внешний сервис генерации для запуска не нужен.

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

После сборки `npm start` запускает локальный просмотр production-сборки через Wrangler. Его адрес выводится в терминале. Сборка использует TypeScript, React 19, Three.js, Vinext/Vite и Tailwind CSS; выбор стека описан в [архитектуре](docs/architecture.md).

## Управление

| Место | Экран | Уборка | Направления | Действие |
| --- | --- | --- | --- | --- |
| 1 | Никита | Рома | WASD | E / пробел |
| 2 | Ярик | Никита | Стрелки | Enter |
| 3 | Рома | Ярик | IJKL | O |

В игре про экран **Q** заряжает бросок общей отвёртки; отпускание бросает, получатель удерживает свою кнопку действия для ловли. В казарме **Q / E** сначала чередуются в ритм, а после происшествия **Q** ненадолго сдерживает поток. Действия у туалета, душа, стиралки и при уборке выполняются удержанием. **Esc** — пауза. Контекстная подсказка уточняет управление текущим этапом.

Геймпад: левый стик или крестовина — движение; **A / ×** — действие; **RB / R1** — Q; **LT / L2** — пылесос; **B / ○** или **Menu / Options** — пауза/назад. Распознанные DualSense, DualShock и Xbox получают свои подписи кнопок при стандартной раскладке браузера. Неизвестный стандартный контроллер получает подписи по положению кнопок; нестандартные схемы не угадываются. Меню, инструктаж, выбор эпизода и пауза доступны с геймпада. После подключения, возврата в окно или смены роли отпустите кнопки, триггеры и стик. **Физические геймпады пока не проверялись.**

В соло один геймпад получает первый набор управления. В игре про экран он контекстно ведёт Никиту на полу и Ярика во время сверления, без переключателя героев. В кооперативе один геймпад назначается второму игроку, оставляя первого клавиатуре; два или три — по порядку игрокам. Исключение: до уборки в казарме доступен только безымянный солдат, поэтому первый геймпад управляет им при любом выбранном числе игроков. После появления бригады назначение обновляется. Текущее назначение показано в помощи.

При сверлении в соло удерживайте **E + левый Shift**: Ярик сверлит и пылесосит, Никита помогает автоматически. В кооперативе Ярик держит **Enter + правый Shift**, Никита — **E** для страховки и **A/D** для баланса. До сверления надо удержать подъём и по очереди принять дрель с пылесосом; после отверстия — удержать спуск.

Последние 30 завершённых полных попыток сохраняются в браузере этого устройства. Повторные прохождения учитываются отдельно. Тренировочные эпизоды не сохраняются и не начисляют очки. Незаконченная попытка, облачная синхронизация и сетевой кооператив не реализованы.


В Windows команда Python может называться `python`. Скрипту нужен Git. Он включает `references/`, записывает SHA-256 каждого файла в `SOURCE-MANIFEST.json` и проверяет целостность ZIP. Оригиналы фотографий также сохранены в Git-репозитории.

## Выпуск версии на GitHub

Репозиторий: [NMGorovenko/Wellcumback](https://github.com/NMGorovenko/Wellcumback). В нём хранятся исходники проекта; тег `v0.2.0` фиксирует первый опубликованный здесь выпуск. Готовую игру нужно скачивать из Assets релиза — архив Source code содержит проект для разработки.

Готовые шаблоны GitHub Actions лежат в `docs/github-actions/`: проверка кода и выпуск по тегу. Они пока не активированы: текущая OAuth-авторизация GitHub не имеет права `workflow`. Чтобы включить автоматическую проверку и публикацию будущих выпусков, перенести эти файлы в `.github/workflows/` с авторизацией, разрешающей изменение workflows. Уже опубликованные релизы шаблон не перезаписывает. Для 0.3.0 также используется ручная проверка, упаковка и публикация. [Скачать версию 0.3.0](https://github.com/NMGorovenko/Wellcumback/releases/tag/v0.3.0).

Для следующего выпуска изменить версию в `package.json` и lock-файле, добавить заметки `docs/releases/vX.Y.Z.md`, сохранить коммит, создать и отправить соответствующий тег. Версия тега должна точно совпадать с `package.json`. Пока Actions не активированы, собрать и приложить файлы к релизу вручную. Проверить упаковку локально после коммита можно так:

```sh
npm ci
npm test
npm run typecheck
npm run lint
npm run build:portable
python3 scripts/package-release.py --tag v0.3.0
```

Готовые файлы появятся в `outputs/release/v0.3.0/`. Сборщик отказывается упаковывать изменённые или несохранённые исходники. Сам ZIP для игры содержит только HTML, инструкцию и BUILD-INFO.json с точным коммитом сборки.
