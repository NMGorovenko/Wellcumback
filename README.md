# Ну, с возвращением!

Подарочный сборник мини-игр для Ромы, которого Ярослав и Никита ждут из армии.

Первый эпизод — 3D-история про установку гигантского экрана. Второй — 2D-пилот «Операция “Чистый проход”» по байке из другой роты. Выбор историй, 1–3 локальных игрока, общий счёт, сохранение результатов в браузере.

## Запуск на Mac / Windows

Нужен Node.js 22.13+; для тестов рекомендован Node.js 24.

```sh
npm ci
npm run dev
```

Открыть адрес `Local`, который напечатает сервер. Если порт 3000 занят, он выберет следующий. Подключение к интернету нужно для первой установки зависимостей; игровые ассеты хранятся в проекте.

```sh
npm test
npm run typecheck
npm run build
```

Вариант из production-сборки: `npm start` после успешного `npm run build`.

Управление показывается в каждом акте. `Esc` — пауза. В первой истории один игрок может играть с помощником; во второй самостоятельная завязка переходит в совместную уборку.

Это первый играбельный прототип. Физика условная; сетевой режим, геймпады, полноценные модели по фотографиям и персональная озвучка — следующие этапы. Третий слот ожидает следующую историю.
