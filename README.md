# Ну, с возвращением!

**[Скачать игру из Releases](https://github.com/NMGorovenko/Wellcumback/releases/latest)** · Текущая версия: **0.2.0**

Подарочный сборник для Ромы, которого Ярослав и Никита ждут из армии. Две трёхмерные истории можно выбирать отдельно или проходить друг за другом; результаты складываются в счёт вечера. Режимы: один игрок с помощником, два или три игрока за одним экраном. Поддерживаются клавиатура, стандартные геймпады и смешанное управление.

**«Экран на полстены».** Квартира по фотографиям: собрать рамку, вставить спицы в отдельное полотно, натянуть пружины общей отвёрткой, просверлить два отверстия со стульев и совместить экран с крючками. Броски можно промахнуть, пружины — перетянуть, отверстия — сделать неровными. Во время подъёма персонажи стоят на полу и держат нижний край.

**«Операция “Чистый проход”».** Сначала игра за безымянного солдата из другой роты: дежурство, попытка дойти до дневального, происшествие, туалет, душ и загрузка испачканных брюк в стиралку. Через стекло виден вращающийся барабан. Сослуживцы реагируют и идут за химзащитой, затем Ярослав, Никита и Рома отмывают машину и реальные следы, оставленные в первой половине. Рома не изображает виновника происшествия.

Визуальное направление — эпоха PS3: узнаваемые фото лиц на объёмных формах, процедурная мебель и выразительные анимации. На экране остаются задача, нужный индикатор и короткая подсказка; подробности открываются в помощи. Фото красного Mustang сохранены для будущей истории, автомобильного геймплея пока нет.

## Где лежит проект

Текущая рабочая папка: `/Users/nikitagorovenko/Documents/ChatGPT/Wellcum back`.

- `lib/game/` — правила, ввод и звук.
- `components/game/` — сцены, персонажи, предметы и HUD.
- `hooks/` — цикл игры, пауза, геймпады и хранение результатов.
- `public/` — ресурсы, которые загружает браузер.
- `references/` — неизменённые фото и исходный рассказ.
- `docs/` — сценарии и техническая документация.
- `tests/` — проверки правил, управления и геометрии.

## Отправить другу файл для игры

Самостоятельная версия собирается командой `npm run build:portable`. Результат: `outputs/portable/Wellcum-back.html`. В нём находятся обе игры, стили, лица и текстуры; сервер, Node.js и аккаунт ChatGPT для игры не нужны. Отправлять можно этот HTML или ZIP с HTML и `README.txt`. Друг скачивает файл и открывает его в обычном настольном браузере, а не в предпросмотре мессенджера.

Офлайн-сборка использует тот же `app/page.tsx` и игровые модули, без копирования механик. `portable/entry.tsx` монтирует игру, `scripts/build-portable.mjs` собирает один обычный скрипт и встраивает ресурсы. Политика содержимого запрещает сетевые соединения. Результаты сохраняются, если браузер разрешает хранилище для локального файла; иначе работают до закрытия вкладки. Это по-прежнему совместная игра за одним компьютером.

Проверены сборка, отсутствие внешних импортов и целостность встроенных изображений. Прямое открытие `file://` запрещено политикой встроенного браузера Codex, поэтому запуск HTML с диска в этой сессии не проверен.

## Запуск на macOS / Windows

Нужен Node.js 22.13 или новее; для разработки и тестов удобно использовать Node.js 24. Команды выполняются из папки проекта:

```sh
npm ci
npm run dev -- --port 3001
```

Открыть [localhost:3001](http://localhost:3001/). Если порт занят, посмотреть фактический адрес в выводе сервера. Первая установка зависимостей требует интернет. Игровые изображения хранятся в проекте; внешний сервис генерации для запуска не нужен.

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

После сборки `npm start` запускает локальный просмотр production-сборки через Wrangler. Его адрес выводится в терминале. Сборка использует TypeScript, React 19, Three.js, Vinext/Vite и Tailwind CSS; выбор стека описан в [архитектуре](docs/architecture.md).

## Управление

| Игрок | Направления | Действие |
| --- | --- | --- |
| 1 | WASD | E / пробел |
| 2 | Стрелки | Enter |
| 3 | IJKL | O |

В игре про экран **Q** заряжает бросок общей отвёртки; отпускание бросает, получатель удерживает свою кнопку действия для ловли. В казарме **Q / E** сначала чередуются в ритм, а после происшествия **Q** ненадолго сдерживает поток. Действия у туалета, душа, стиралки и при уборке выполняются удержанием. **Esc** — пауза. Контекстная подсказка уточняет управление текущим этапом.

Геймпад: левый стик или крестовина — движение; **A / ×** — действие и подтверждение; **RB / R1** — Q; **B / ○** или **Start** — пауза/назад. Меню, инструктаж и пауза также управляются с геймпада. После подключения, возвращения в окно или смены роли сначала отпустить кнопки и стик.

В соло один геймпад управляет первым игроком. В кооперативе один геймпад назначается второму игроку, оставляя первого клавиатуре; два или три — по порядку игрокам. Исключение: до уборки в казарме доступен только безымянный солдат, поэтому первый геймпад управляет им при любом выбранном числе игроков. После появления бригады назначение обновляется. Текущее назначение показано в помощи.

Последние 30 завершённых попыток сохраняются в браузере этого устройства. Повторные прохождения учитываются отдельно. Незаконченная попытка, облачная синхронизация и сетевой кооператив не реализованы.

## Выпуск версии на GitHub

Репозиторий: [NMGorovenko/Wellcumback](https://github.com/NMGorovenko/Wellcumback). `main` содержит актуальные исходники, а тег `v0.2.0` фиксирует первый опубликованный здесь выпуск. Готовую игру нужно скачивать из Assets релиза — архив Source code содержит проект для разработки.

Готовые шаблоны GitHub Actions лежат в `docs/github-actions/`: проверка кода и выпуск по тегу. Они пока не активированы: текущая OAuth-авторизация GitHub не имеет права `workflow`. Чтобы включить автоматическую проверку и публикацию будущих выпусков, перенести эти файлы в `.github/workflows/` с авторизацией, разрешающей изменение workflows. Уже опубликованные релизы шаблон не перезаписывает. Текущий выпуск собран и опубликован вручную теми же командами проверки и упаковки.

Для следующего выпуска изменить версию в `package.json` и lock-файле, добавить заметки `docs/releases/vX.Y.Z.md`, сохранить коммит, создать и отправить соответствующий тег. Версия тега должна точно совпадать с `package.json`. Пока Actions не активированы, собрать и приложить файлы к релизу вручную. Проверить упаковку локально после коммита можно так:

```sh
npm ci
npm test
npm run typecheck
npm run lint
npm run build:portable
python3 scripts/package-release.py --tag v0.2.0
```

Готовые файлы появятся в `outputs/release/v0.2.0/`. Сборщик отказывается упаковывать изменённые или несохранённые исходники. Сам ZIP для игры содержит только HTML, инструкцию и BUILD-INFO.json с точным коммитом сборки.
