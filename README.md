Подарочный сборник для Ромы, которого Ярослав и Никита ждут из армии. Четыре трёхмерные истории связаны поездкой на красном Mustang по условному Красноярску; третья история — день переезда Ярика и Насти. Можно подъехать к миссии или открыть быстрый список; результаты складываются в счёт вечера. Локальные режимы: один, два или три игрока за одним экраном. В настольной и веб-версии доступны комнаты на 2–3 компьютера для всех историй; условия подключения описаны ниже. В соло экран собирают Никита и Ярик; казарму Рома убирает один. В переезде Ярик и Настя, третий участник — Никита; в соло Настя помогает сама. Поддерживаются клавиатура, стандартные геймпады и смешанное управление.

**«Экран на полстены».** Квартира по фотографиям: собрать рамку, вставить спицы в отдельное полотно, натянуть пружины общей отвёрткой, просверлить два отверстия со стульев и совместить экран с крючками. Никита стоит на полу, страхует и подаёт; Ярик забирается, по очереди принимает дрель и пылесос и работает ими одновременно. Кирпичная пыль остаётся на белой стене, если забыть пылесос. После падения Ярик возвращается на пол, снова забирается и получает оба инструмента. Готовые отверстия сохраняются.

**«Операция “Чистый проход”».** Сначала игра за безымянного солдата другой роты: дежурство, дневальный с крепкими репликами, происшествие, туалет, душ и загрузка брюк в стиралку. До уборки управляется только солдат, гости наблюдают. После загрузки брюк Рома подходит к стиралке и реагирует; следом старший приказывает надеть химзащиту. Реплики показываются комиксами у говорящего. На общей уборке главное место в кооперативе получает другой сослуживец, Рома остаётся помощником. Никиты и Ярика в казарме нет. В одиночку убирает только Рома. Пять помещений отделены от плиточного коридора; деревянная тумба, красная накладка, телефон и стенды опираются на фото российской казармы. Рома не изображает виновника происшествия. Очки за пол начисляются один раз после завершения уборки: лишние следы не повышают потенциальный рекорд.

Визуальное направление — эпоха PS3: узнаваемые фото лиц на объёмных формах, процедурная мебель и выразительные анимации. Рядом с персонажами показаны короткие контекстные подсказки: что нажать, держать или отпустить сейчас. В историях про экран и уборку казармы есть выбор эпизода: новая тренировочная попытка начинается с нужного места, остаётся с нулевыми очками и не меняет счёт вечера. На карте уже можно ездить, дрифтить и сталкиваться с бордюрами. В Mustang сидят все трое; ездовые виды, общий план города и ракурс лиц переключаются вручную. Город занимает 4250×3400 игровых метров: семь районов, крупные мосты через Енисей, короткие мосты через Качу, острова с проездами, Студгородок, Удачный, Академгородок и отдельные торговые центры. Длинные перегоны и мосты сжаты с сохранением взаимного положения ориентиров; фасады и силуэты опираются на [публичные референсы](docs/city-krasnoyarsk-references.md). Маршрут Студгородок → Планета рассчитан на 2–3 минуты обычной поездки. Это приближённый игровой город; автомобильный проезд по Виноградовскому мосту — аркадное допущение.

**«Переезд Ярика и Насти».** Обставленная студия по фотографиям, 22 предмета и шесть жёлтых сумок по 18 кг. Сначала упаковка, затем вынос; усталость и отдых на диване, комиксные реплики над головой и неожиданные дела посреди дня. В соло Настя собирается сама; вдвоём у каждого свой герой. DevOps-инциденты теперь требуют двух коротких действий у ноутбука с отпусканием кнопок между шагами; их вид чередуется. Наклон тела и высота сумки отражают вес на конкретного носильщика и усталость. Глава заканчивается у двери; лифт и перевозка в новую квартиру остаются продолжением.

**«Байки Ромы 2».** В туалете нет бумаги. Нужно выйти из кабинки, добраться до ведра с тряпками и вернуться незамеченным: посетитель приходит, моет руки и оглядывается. Перегородки скрывают от взгляда, подозрение растёт постепенно; после обнаружения игрок возвращается в кабинку, сохраняя выполненные части истории. За 1–3 игроков, локально и в общей онлайн-комнате. [Сценарий](docs/scenarios-roma2.md).

**Онлайн.** Из приложения можно поднять сервер и скопировать строку `WCB1:…` для друга на Windows или Mac. Доступны город, экран, казарма, переезд и «Байки Ромы 2». Ведущий рассчитывает мир; разрыв связи ставит общую паузу. LAN и отдельный гостевой процесс проверены. Временный интернет-туннель пока не прошёл проверку на текущей сети из-за обрыва TLS до Cloudflare; подготовлен вариант [своего сервера](docs/server.md). [Как подключаться](docs/network.md).

игры и новое приглашение; опубликованные настольные пакеты 0.15.1 с этой
географией и текущим сетевым протоколом несовместимы.

## Отправить другу файл для игры

Самостоятельная версия собирается командой `npm run build:portable`. Результат: `outputs/portable/FRIENDSLOP.html`. В нём находятся четыре истории, карта, стили, лица и текстуры; сервер, Node.js и аккаунт ChatGPT для игры не нужны. Отправлять можно этот HTML или ZIP с HTML и `README.txt`. Друг скачивает файл и открывает его в обычном настольном браузере, а не в предпросмотре мессенджера.

Офлайн-сборка использует те же игровые модули без копирования механик. HTML содержит все ресурсы и работает за одним компьютером. Для онлайна скачай приложение macOS/Windows либо открой веб-версию; автономный HTML остаётся без сетевого доступа. DMG/ZIP предназначены для Mac, portable EXE и установщик — для Windows. [Руководство настольной версии](docs/desktop-build.md).

Проверка самостоятельной сборки включает сборку HTML, синтаксис, отсутствие внешних импортов и целостность встроенных ресурсов. Открытие скачанного файла через `file://`, звук, устройства и браузерный маршрут проверяются отдельно. Фактические результаты 0.7 приведены в [отчёте проверки](docs/acceptance-v0.7.0.md).

## Запуск на macOS / Windows

Нужен Node.js 22.13 или новее; для разработки и тестов удобно использовать Node.js 24. Команды выполняются из папки проекта:

```sh
npm ci
npm run dev -- --port 3001
```

Открыть [localhost:3001](http://localhost:3001/). Если порт занят, посмотреть фактический адрес в выводе сервера. Первая установка зависимостей требует интернет. Игровые изображения хранятся в проекте; внешний сервис генерации для запуска не нужен.

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

После сборки `npm start` запускает локальный просмотр production-сборки через Wrangler. Его адрес выводится в терминале. Сборка использует TypeScript, React 19, Three.js, Vinext/Vite и Tailwind CSS; выбор стека описан в [архитектуре](docs/architecture.md).

## Управление

Игра занимает всё окно; **F** или значок в углу включает системный полный экран. Кнопки и цели лежат поверх сцены. В городе по умолчанию камера смотрит сзади под углом: чем выше скорость, тем шире обзор и больше дороги впереди. Кнопка камеры переключает «За машиной → Низкая камера → Весь город → Лица». Низкий перспективный вид позволяет смотреть дальше вперёд; быстрый вызов — **C** (если не переназначена) или **Y / △** на геймпаде. Миникарта в углу показывает дорогу, положение машины и выбранную историю; нажатие раскрывает весь город. Полный газ теперь заметно мощнее, небольшой ход триггера удобен для парковки. Mustang уходит в мягкий занос при быстром повороте сам; пробел усиливает скольжение.

На карте: **W/S** — газ и тормоз/назад, **A/D** — руль, **пробел** — усилить занос, **E** — начать историю после остановки, **Q** — сигнал. На геймпаде: левый стик — плавный руль, **RT/R2** — плавный газ, **LT/L2** — тормоз/назад, **X/□** — усилить занос, **A/×** — история. Машиной управляет клавиатура и первый подключённый геймпад.

В паузе карты можно выбрать историю, число игроков, камеру и открыть управление без мыши. В настройках отдельные вкладки машины и каждого игрока, затем клавиатуры и геймпадов. Карта и мини-игры сохраняют свои клавиши независимо; **пробел у дома никогда не запускает историю**. На карте он занят дрифтом, в мини-играх остаётся дублем действия первого игрока.

| Место | Экран  | Уборка                   | Направления | Действие   |
| ----- | ------ | ------------------------ | ----------- | ---------- |
| 1     | Никита | Сослуживец (в соло Рома) | WASD        | E / пробел |
| 2     | Ярик   | Рома                     | Стрелки     | Enter      |
| 3     | Рома   | Боец                     | IJKL        | O          |

В игре про экран **Q** заряжает бросок общей отвёртки; отпускание бросает, получатель удерживает свою кнопку действия для ловли. В казарме **Q / E** сначала чередуются в ритм, а после происшествия **Q** ненадолго сдерживает поток. Действия у туалета, душа, стиралки и при уборке выполняются удержанием. **Esc** — пауза, **F** — полный экран. Управление переназначается в настройках с проверкой конфликтов и сбросом; настройки доступны из меню и паузы. Контекстная подсказка уточняет управление текущим этапом.

Геймпад: левый стик или крестовина — движение; **A / ×** — действие; **RB / R1** — Q; **LT / L2** — пылесос; **B / ○** или **Menu / Options** — пауза/назад. Распознанные DualSense, DualShock и Xbox получают свои подписи кнопок при стандартной раскладке браузера. Неизвестный стандартный контроллер получает подписи по положению кнопок; нестандартные схемы не угадываются. Меню, инструктаж, выбор эпизода и пауза доступны с геймпада. После подключения, возврата в окно или смены роли отпустите кнопки, триггеры и стик. **Физические геймпады пока не проверялись.**

В соло один геймпад получает первый набор управления. В игре про экран он контекстно ведёт Никиту на полу и Ярика во время сверления, без переключателя героев. В кооперативе один геймпад назначается второму игроку, оставляя первого клавиатуре; два или три — по порядку игрокам. В казарме это назначение сохраняется с начала до конца: при локальной совместной игре один геймпад управляет Ромой, клавиатура — сначала безымянным солдатом, затем другим сослуживцем. В онлайн-комнате каждый компьютер использует первый локальный набор ввода, который переводится в закреплённое сетевое место. Текущее назначение показано в помощи.

При сверлении в соло удерживайте **E + левый Shift**: Ярик сверлит и пылесосит, Никита помогает автоматически. В кооперативе Ярик держит **Enter + правый Shift**, Никита — **E** для страховки и **A/D** для баланса. До сверления надо удержать подъём и по очереди принять дрель с пылесосом; после отверстия — удержать спуск.

Последние 30 завершённых полных попыток сохраняются в браузере этого устройства. Повторные прохождения учитываются отдельно. Тренировочные эпизоды не сохраняются и не начисляют очки. Незаконченные локальные попытки и облачные результаты не сохраняются. Временный снимок онлайн-комнаты нужен для восстановления прежнего участника, в том числе кнопкой «Вернуться в комнату» после закрытия вкладки и не является облачным сохранением прогресса. Итоги показывают пройденные истории и до четырёх памятных номинаций по реальным данным одного прохождения; приветствие Роме появляется после всех четырёх разных историй.

Онлайн поддерживает передачу ведущего и паузу при разрыве связи без рестарта. Приложение создателя комнаты остаётся открытым; после возвращения участников продолжение запускается вручную. Подробности — в [правилах сети](docs/network.md).

Полный архив кода, документов, игровых ресурсов и оригиналов:

```sh
python3 scripts/archive-source.py outputs/friendslop-source.zip
```

В Windows команда Python может называться `python`. Скрипту нужен Git. Он включает `references/`, записывает SHA-256 каждого файла в `SOURCE-MANIFEST.json` и проверяет целостность ZIP. Оригиналы фотографий также сохранены в Git-репозитории.

Тесты правил и геометрии не заменяют браузерное прохождение: обзор камеры, анимации и физические геймпады проверяются отдельно на целевом экране. Этот README описывает реализацию и команды; завершение приёмки и публикации фиксируется для конкретной сборки.

Восстановление связи через настоящий интерфейс Electron проверяется отдельно:

```sh
npm run build:portable
npm run desktop:prepare
node scripts/smoke-recovery.mjs
```

Последняя команда проверяет уже подготовленное приложение в `outputs/desktop-app`, открывая временные профили создателя и гостя. Реальные renderer, preload, IPC и loopback WebSocket используются с подставным провайдером туннеля: проверяются авария, неудачный retry, новое приглашение и возврат с прежней ролью и прогрессом. Пользовательские сохранения не затрагиваются. Успешный результат и SHA-256 проверенных файлов записываются в `outputs/recovery-ui.json`; этот тест не подтверждает публичное интернет-соединение.

## Выпуск версии на GitHub

Репозиторий: [NMGorovenko/Wellcumback](https://github.com/NMGorovenko/Wellcumback). В нём хранятся исходники проекта; тег `v0.2.0` фиксирует первый опубликованный здесь выпуск. Готовую игру нужно скачивать из Assets релиза — архив Source code содержит проект для разработки.

Готовые шаблоны GitHub Actions лежат в `docs/github-actions/`: проверка кода и выпуск по тегу. Они пока не активированы: текущая OAuth-авторизация GitHub не имеет права `workflow`. Чтобы включить автоматическую проверку и публикацию будущих выпусков, перенести эти файлы в `.github/workflows/` с авторизацией, разрешающей изменение workflows. Уже опубликованные релизы шаблон не перезаписывает. Сейчас используется ручная проверка, упаковка и публикация.

Для следующего выпуска изменить версию в `package.json` и lock-файле, добавить заметки `docs/releases/vX.Y.Z.md`, сохранить коммит, создать и отправить соответствующий тег. Версия тега должна точно совпадать с `package.json`. Пока Actions не активированы, собрать и приложить файлы к релизу вручную. Проверить упаковку локально после коммита можно так:

```sh
npm ci
npm test
npm run typecheck
npm run lint
npm run build:portable
npm run desktop:mac:signed
npm run desktop:win
npm run build:server
node scripts/smoke-server.mjs
python3 scripts/package-release.py --tag v0.11.3 --desktop
```

Готовые файлы появятся в `outputs/release/v0.11.3/`. Сборщик отказывается упаковывать несохранённый код, устаревший renderer или relay. Выпуск содержит исходники, оригиналы фотографий, серверный пакет и SHA-256 всех файлов.
