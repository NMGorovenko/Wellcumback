# Приёмка 0.11.1 — выбор сети

- TypeScript, lint и 385 тестов прошли, 0 пропущено на этой машине. `outputs/tests-v0111-final.log`, целевые проверки `outputs/tests-v0111-network.log`.
- Проверены границы диапазона 100.64/10 и запрет соседних публичных диапазонов, недопустимых адресов/hostname; приглашение туда и обратно сохраняет выбранный адрес.
- Список сетей доступен до запуска, сохраняет имя интерфейса, исключает loopback, IPv6 и дубликаты. IPv6 VPN не входит в эту итерацию.
- При нескольких адресах требуется выбор. Main-процесс повторно сверяет адрес с текущими интерфейсами, до остановки ресурсов. Исчезнувший/поддельный адрес не закрывает существующую комнату. Параллельные разные запросы запуска не получают сервер чужого интерфейса. Прямые запросы создателя достигают выбранного LAN listener.
- Реальное окно Electron на Apple Silicon: открыто «Онлайн», выбран режим «Одна сеть / VPN», выбран показанный IPv4, нажата «Создать игру», появился код; комната корректно закрыта. Затем sandboxed preload поднял сервер на выбранном адресе и отдельный Node-гость обменялся четырьмя сценами, вводом и ACK. Все фазы native smoke прошли: `outputs/desktop-smoke-v0111.log`.
- Набор native smoke также подтвердил сохранения между запусками, клавиатуру, программные Xbox/DualSense и комиксы переезда. Сообщение IPC о закрытии сокета при явной остановке сервера ожидаемо; тест завершился успешно.

- Собраны Mac arm64/x64 ZIP/DMG и Windows x64 portable/setup EXE; веб-сборка прошла. Серверный пакет прошёл миграцию старой базы, перезапуск, reconnect-barrier; LAN приглашение прошло отдельную проверку транспорта. Логи `outputs/desktop-mac-v0111.log`, `outputs/desktop-win-v0111.log`, `outputs/build-v0111.log`.
- В инструкции VPS уточнены пользователь/группа, каталог ключа, применение Caddyfile и проверка двух клиентов после health. Развёртывание остаётся непроверенным без предоставленного хоста.

## Что не подтверждено

Системная VPN не устанавливалась и не настраивалась. Пользовательский выбор сети проверен на настоящем локальном интерфейсе. Адреса overlay VPN проверены на правилах выбора и приглашениях; два физических компьютера в общей виртуальной сети отсутствуют. Публичный временный туннель по-прежнему упирается в сетевую ошибку из приёмки 0.10. Работа Windows/Mac через разные сети пока не доказана.

Текущий возврат после дисконнекта требует работающего процесса сервера. Аварийный выход самого процесса туннеля закрывает встроенный relay; восстановление после такой аварии пока не реализовано. Это отличается от временного обрыва транспорта, при котором комната остаётся и ждёт на паузе.

VPS, платные ресурсы, аккаунты и приглашения сторонним пользователям не создавались. Доступ сайта не расширялся. Физические геймпады, Intel Mac и Windows остаются без аппаратной проверки. Исходники и оригиналы фотографий сохраняются в архиве релиза.
