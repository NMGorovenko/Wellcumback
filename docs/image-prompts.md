## Пол квартиры — версия 2

Built-in image_gen. Референс: фотография комнаты `references/room/codex-clipboard-5c413cd6-7eae-49ce-9c7c-d9d56f159b94.jpg`. Результат: `public/materials/apartment-oak-v1.png`, native 1254×1254. Исходник генерации сохранён без изменения пикселей. sRGB albedo + слабая высота из яркости; mirrored repeat в Three.js.

```text
Use case: photorealistic-natural. Asset type: seamless tileable diffuse/albedo texture for an oak floor in a small Russian apartment game with an early PlayStation 3 material aesthetic. Generate exactly ONE square 1024 × 1024 texture image. Strict straight-down orthographic scan of the wood surface only, filling every pixel edge to edge. Warm medium-brown oak laminate boards, muted honey and soft grey-brown tones, natural fine longitudinal wood grain, occasional restrained oak knots, subtle authentic wear. Straight parallel medium-width boards run vertically from top to bottom, around six to eight board widths across the image, staggered end joints. Floor reference observed: medium warm oak apartment planks, not orange pine or dark walnut. This is a NEW material asset, not a room photograph. Seamless periodic edges horizontally and vertically: board spacing and grain continue across opposing edges without a visible border. Uniform neutral diffuse illumination, flat even albedo suitable for adding live game lighting; subtle color variation between planks. No directional lighting, no reflected light, no baked shadow, no ambient-occlusion vignette, no perspective, no furniture, no objects, no walls, no borders, no text, no labels, no watermark, no decorative parquet or herringbone pattern. Only the oak planks as a production-quality game material texture.
```
