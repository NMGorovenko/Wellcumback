# FRIENDSLOP 0.17.0 — разрушаемое окружение и начало доработки центра

24 сентября 2026. Включает изменения рельефа/загрузки из 0.16.

## Поведение

- Сильный поперечный удар отламывает отдельную секцию металлических перил.
  Лёгкое касание и скольжение вдоль перил не разрушают их. Бордюр и пролёт
  остаются целыми. Секция наклоняется, смещается и остаётся лежать.
- Городские деревья получили столкновения. После сильного удара дерево падает
  по направлению движения, машину замедляет. Через упавшее дерево можно проехать.
  Дальние лесные декорации Бобрового лога и гор не разрушаются.
- Удар звучит коротким металлическим/деревянным шумом, учитывает настройки
  звука и паузу. Голосовой озвучки не добавлено. В гонке столкновение сбрасывает
  незачтённую дрифтовую серию; повреждения общие для всех автомобилей заезда.
- Сохраняется компактная строка повреждений и последние 16 анимационных событий.
  Старые повреждения не исчезают при вытеснении событий. Повторное подключение
  восстанавливает упавшие объекты без повторной анимации давних ударов.
  Быстрое перемещение и возврат машины на дорогу не чинят город.
  Новая поездка/гонка начинает с целым окружением.
- В центре уточнён фасад оперы, добавлены колонна Аполлона, фонтан и мощение
  перед театром. Скульптура/масштаб упрощены; Пушкин и музей ещё из прошлой итерации.

## Проверка

Целевые тесты: слабый/скользящий/сильный удар, проезд автомобиля через сломанный
объект, неподвижные и упавшие матрицы, стабильное число графических ресурсов,
восстановление из JSON и настоящая запись/переподключение через SQLite комнаты.
Встроенный браузер: старт без провала, падение дерева и секции от обычной физики,
загрузка и Театральная площадь. Для осмотра используется отдельная dev-сцена,
которая не читает пользовательские сохранения.

Полный набор: **665/665 тестов**, без пропусков. TypeScript и lint проходят.
Собраны Cloudflare Worker/клиент и переносимый `FRIENDSLOP.html` (26,1 МиБ).
Встроенный браузер: все перечисленные сцены проверены, ошибок/предупреждений
в консоли нет. Разрушения проверены через настоящую физику автомобиля;
сетевое сохранение — через SQLite и повторный вход участника в комнату.

Проверка выполнена в отдельной временной копии с `npm ci` по зафиксированному
lockfile: часть исходных `node_modules` и старых файлов рабочей папки выгружена
FileProvider/iCloud и блокирует чтение. Исходники восстановлены из Git,
фотографии не заменялись и не пересоздавались.

## Ограничения

Аркадные разрушения окружения: без обрушения мостов, сложной физики обломков,
повреждения кузова или уничтожения домов. Упавшие объекты не блокируют трассу.
История разрушений общая в текущей сцене; отдельной долговременной сохранённой
карты разрушений между сессиями нет. Физические геймпады, сетевой пинг между
реальными Windows/Mac и новые настольные пакеты не проверялись.
Настольный опубликованный релиз остаётся 0.15.1; установленное приложение и
оригинальные фотографии не изменялись.
