# Приёмка 0.12.1

13 сентября 2026. Единая подача реплик комиксами; городской диалог
привязан к реальным головам пассажиров Mustang.

## Проверки

Численная проекция настоящей модели Mustang: все три пассажира, камеры
поездки/лиц/карты, четыре направления, остановка и скорость 32 м/с,
размеры 1440×900, 1920×1080 и 390×844. Текст остаётся внутри кадра,
кончик хвоста совпадает с положением говорящего с небольшим зазором.
Отдельно проверен большой сдвиг облачка вокруг высокой угловой панели.

Проверены исчезновение на паузе, окончание срока реплики, восстановление
из JSON и отсутствие вымышленного говорящего у сетевых уведомлений.
Настоящий движок казармы проверяет вопрос солдата, последовательный ответ
дневального, реплику Ромы после полоскания швабры и отсутствие повторного
запуска при удержании действия. Смена роли не переносит реплику солдата к Роме.
Бросок отвёртки вызывает «Лови!» у бросающего и сохраняет последующий лов.

Новый ручной браузерный осмотр не проводился. Численные проверки не заменяют
оценку внешнего вида человеком. Физические геймпады, Windows, Intel Mac и
интернет-пара из разных сетей в этой итерации отдельно не проверялись.
Mac подписывается Developer ID; нотариализации Apple пока нет.

Все **441 тест**, TypeScript, Oxlint и production-сборка прошли.
Логи: `outputs/tests-v0121.log`, `typecheck-v0121.log`, `lint-v0121.log`,
`build-v0121.log`. Проверка верхней границы карты также подтверждает, что
облачко переносится ниже головы, а хвост не перекрывает текст.

## Готовые приложения

Собраны Mac arm64/x64 ZIP и DMG, Windows x64 portable/setup и сервер.
Все четыре Mac-контейнера проверены после извлечения: версия, архитектура,
SHA-256, Developer ID, hardened runtime, подписанный tunnel helper,
совпадение игрового ASAR и соответствие исходникам. Нотариализации нет.

Готовый ARM64-клиент прошёл запуск 3D, изоляцию renderer, управление поездкой,
реальный AudioContext и продвижение часов устройства, создание LAN-комнаты
через интерфейс и подключение отдельного гостя с получением снимка города.
Приложение корректно завершилось, подписанный бандл не изменился.

Исходная проверка встретила две особенности тестового окружения: одного
`Page.bringToFront` было недостаточно для фокуса окна; раннее подключение
отладчика воспроизводило внутреннюю ошибку Electron `startupData`.
Для повторной проверки тот же готовый ZIP запускался с активацией точного PID
и задержкой подключения отладчика на секунду. Счётчик событий создания узлов
не может учитывать узлы до подключения; реальный AudioContext и продвижение
аудиочасов остались обязательными. Этот запуск завершился без ошибок renderer.
Первоначальные неудачные логи сохранены отдельно, код игрового приложения
для повторной проверки не изменялся. Установленная копия и её профиль не затронуты.

Серверный пакет проверен в отдельном процессе: два WebSocket-клиента,
обновление SQLite, рестарт, переподключение с паузой и корректная остановка.
Windows-сборки получены на Mac; физический Windows не запускался.

Отчёты: `outputs/mac-artifacts-v0121.json`, `native-focused-v0121.log`,
`signed-mac-smoke-v0121.log`, `desktop-win-v0121.log`, `server-smoke-v0121.log`.
Сайт опубликован до версии 18 из коммита `f5c31d3`; последующий коммит меняет
приёмочные документы. Архив исходников и оригиналы фотографий проверяются
при упаковке; файлы GitHub сверяются по SHA-256 перед открытием релиза.
