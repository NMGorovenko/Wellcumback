# 0.11.1 — выбор сети для друга

В настольном приложении режим «Одна сеть / VPN» показывает адреса доступных сетей. Если их несколько, можно выбрать нужную: сервер и приглашение используют этот адрес. Поддержаны домашние сети и диапазон 100.64/10, используемый Tailscale. Пропавшую сеть и посторонний адрес игра отклоняет без закрытия текущей комнаты.

Чтобы играть через VPN, компьютеры должны видеть друг друга в общей виртуальной сети. Обычный VPN для выхода в интернет этого не гарантирует. Настраивать сеть надо отдельно; приложение не меняет системные настройки.

Передача ведущего, возврат в прежнюю роль и пауза после дисконнекта из 0.11.0 сохранены. Создатель комнаты оставляет своё приложение открытым. Доступ к закрытому сайту по коду комнаты не выдаётся.

Проверены 385 автоматических тестов, создание через настоящее окно Mac-приложения, выбранный LAN listener и отдельный клиент. Пара Windows/Mac через разные физические сети пока не проверена; временный интернет-туннель в текущей сети недоступен. Сборки macOS не нотарифицированы Apple, Windows не проверена на физическом компьютере. Протокол остаётся 5; для VPN-адресов обоим рекомендуется обновиться до 0.11.1.
