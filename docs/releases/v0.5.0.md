# 0.5.0 — понятнее управление, приложения для Mac и Windows

Дрифт Mustang перенесён на пробел. Машина и персонажи получили отдельные настройки клавиш; геймпад управляет рулём и курками плавно. Игру можно скачать как настольное приложение с теми же историями и сохранениями между запусками.

## Что изменилось

- **Машина:** WASD, пробел — дрифт, E — начать историю, Q — сигнал. Рядом с домом пробел больше не запускает миссию. На геймпаде левый стик поворачивает, RT/R2 даёт газ, LT/L2 тормозит и включает задний ход, X/□ дрифтит, A/× начинает историю. Лёгкое касание тормоза больше не обрезает скорость до лимита заднего хода.
- **Настройки:** отдельные вкладки машины и трёх игроков, затем клавиатуры/геймпадов. Переназначения сохраняются, конфликтующие клавиши не принимаются. Старые настройки персонажей сохраняются после обновления; машина получает свою раскладку.
- **Без мыши:** пауза карты открывает истории, выбор игроков и цели поездки, камеры, управление и полный экран. Доступна передача руля в сетевом эксперименте. В списке эпизодов выбранный пункт прокручивается в видимую область. На результате истории про экран доступны продолжение, возврат и повтор.
- **Контроллеры:** подписи Xbox и PlayStation, автоматическое назначение одного–трёх геймпадов, смешанный режим с клавиатурой. Мёртвые зоны и ожидание отпускания после подключения, паузы, смены роли и восстановления связи. Машину ведёт первый геймпад; мини-игры используют выбранное число игроков.
- **Desktop:** общий автономный renderer упакован в Electron 44.3.0 и electron-builder 26.16.1. macOS Apple Silicon/Intel — ZIP и DMG, Windows x64 — portable EXE и установщик. Игроку не нужны Node.js или сервер. Стабильный внутренний адрес сохраняет настройки и счёт после обновления; веб-сохранения автоматически не импортируются. Команды сборки и проверки — в [инструкции](../desktop-build.md).
- Исходники оболочки, тесты и сценарии входят в архив проекта. Все 27 оригинальных референсов сохранены. Версии 0.2.0, 0.3.0 и 0.4.0 остаются доступны.

## Проверка

Версия `0.5.0`, 12 сентября 2026. Точный коммит фиксируется тегом и `BUILD-INFO.json` переносимого ZIP. Проверены:

- **209 тестов без пропусков:** полные истории для 1–3 игроков, новые раскладки и миграция, аналоговое управление и торможение, нейтраль после переподключения/потери связи, экран результатов и безопасность настольного renderer. TypeScript и lint проходят.
- Встроенный браузер: настройки машины/геймпадов, изменение числа игроков стрелками, клавиатурный маршрут карта → пауза → управление, список историй → Escape → карта. Интерфейс не требует мыши для этих действий.
- **Реальный Electron на macOS arm64:** WebGL, игровой интерфейс, отсутствие ошибок renderer, нативный fullscreen и выход, открытие/закрытие настроек, сохранение localStorage через два отдельных запуска во временном профиле. Обычные события клавиатуры доводят Mustang до доступной миссии; пробел оставляет машину на карте.
- В том же настольном тесте **имитированные** Xbox и DualSense с разными индексами проходят обнаружение, подписи, паузу/возврат и смену водителя после отключения. Это проверка сквозного маршрута ввода, не аппаратная проверка.
- Собраны четыре macOS пакета (ZIP/DMG, arm64/x64) и два Windows x64 EXE (portable/NSIS). Оба macOS ZIP распакованы и проверены: целостность, архитектура исполняемого файла, `codesign --verify --deep --strict`, совпадение ASAR с проверенными HTML и runtime. Windows EXE собраны на Mac; запуск на Windows остаётся отдельной проверкой.
- Production web и автономный HTML собираются. Пакеты macOS собираются вне FileProvider/iCloud: это устраняет повторное добавление FinderInfo во время подписи. Оригинальные фотографии проверяются по SHA-256 при упаковке релиза.

Полные новые прохождения на физических геймпадах, запуск на Windows и отдельный запуск на Intel Mac не проверялись. Общие правила историй проверены тестами; звук через реальные колонки и вибрация контроллеров отдельно не проверялись.

## Скачать

Для Windows проще всего `Wellcum-back-0.5.0-windows-x64-portable.exe`: скачать и запустить. `setup.exe` устанавливает приложение для текущего пользователя.

Для Mac выбрать `mac-arm64` (Apple Silicon) или `mac-x64` (Intel). DMG содержит приложение; ZIP — тот же вариант в архиве. macOS-пакеты имеют локальную ad-hoc подпись без notarization, Windows EXE не подписаны издателем: система может запросить подтверждение запуска. Отдельная проверка на Windows и физические DualSense/Xbox пока не выполнены.

Сохранён и лёгкий формат `play.zip` / `.html` для настольного браузера. `source.zip` содержит исходники и оригиналы, `SHA256SUMS.txt` — контрольные суммы всех девяти игровых/исходных пакетов. Настольная версия автономная; сетевые мини-игры ещё не реализованы, надёжная интернет-связь экспериментальной карты не подтверждена.
