# 0.11.2 — сохранить вечер при обрыве связи

Если процесс интернет-туннеля аварийно закрывается, встроенный сервер теперь сохраняет комнату и ставит прохождение на паузу. В окне «Онлайн» создатель нажимает «Восстановить интернет-связь». Неудачная попытка не удаляет комнату; можно попробовать снова.

После восстановления адрес может измениться. Создатель копирует новое приглашение, а друг вставляет его в «Онлайн → Обновить приглашение». Возврат использует прежнее личное подключение: роль, предметы и прогресс сохраняются. Все отпускают кнопки; текущий ведущий продолжает вручную. Обычный временный дисконнект по-прежнему восстанавливается автоматически.

Исправлены гонки остановки и повторного запуска: поздний ответ старого соединения не заменяет актуальное состояние, старый туннель не закрывает новый, а последняя команда остановки отменяет ожидающий запуск.

394 автоматических теста прошли. Авария провайдера моделировалась в тестах с настоящим локальным сервером и WebSocket; это не подтверждает доступность Cloudflare из разных сетей. Для реальной проверки Windows ↔ Mac всё ещё нужны два компьютера в доступной общей сети или работающий публичный сервер. Приложение создателя остаётся открытым. Протокол 5; обоим участникам рекомендуется версия 0.11.2. macOS-сборки без нотарификации Apple, физический Windows и геймпады не проверены.
