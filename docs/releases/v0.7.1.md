# 0.7.1 — соединение с медленным сервером комнат

На опубликованном сайте запросы комнаты занимали 1–3 секунды. Пороги первой версии принимали это за потерю участника и ставили игру на паузу. Исправление учитывает измеренную задержку и оставляет конечный предел ожидания; настоящий разрыв по-прежнему освобождает управление.

Полировка трёх историй, итоги вечера и локальная игра сохраняются из [0.7.0](v0.7.0.md). Онлайн остаётся экспериментальным: только город и экран в браузере. HTTP relay может давать заметную задержку; исправление ложных пауз не превращает его в транспорт с низкой задержкой. Для дальнейшего развития нужен отдельный транспорт для частых игровых сообщений.

В Assets этого исправления: автономный HTML, play.zip, source.zip и SHA256SUMS.txt. Готовые приложения Mac arm64/x64 (DMG/ZIP) и Windows x64 (portable/installer) остаются в [выпуске 0.7.0](https://github.com/NMGorovenko/Wellcumback/releases/tag/v0.7.0): локальная игра в них не затронута исправлением веб-комнат. Версия этих приложений остаётся 0.7.0. Настольные приложения и HTML работают локально. Сайт сохраняет текущие права доступа; код комнаты не открывает закрытый сайт другу.

## Проверки

Выпуск 0.7.0 прошёл 320 автоматических проверок, локальный обмен двух настоящих веб-клиентов и запуск Electron на Mac arm64. Для 0.7.1 прошли 327 автоматических тестов, TypeScript и lint. Сетевой патч отдельно проверяет RTT 1,3 и 3 секунды, ограничение ожидания, переподключение, короткие нажатия и очередь аналогового ввода, разную задержку у ведущего и гостя и освобождение кнопок после паузы. Разные физические устройства, сети и геймпады ещё не проверены.
