# FRIENDSLOP 0.13.0 — гонки с друзьями

Игра теперь называется FRIENDSLOP. Сохранения и настройки остаются на месте.

На городской карте появился гараж для отдельных гонок. Выбирайте Красноярск
или компактную Nordschleife, Mustang или AMG ONE, цвет машины и один/три круга.
В обычной гонке нужно пройти ворота по порядку. В дрифте серия приносит очки
после выхода из заноса, а столкновение сжигает её. Таблица мест, миникарта,
следы шин, дым и звуки работают в каждом игровом виде.

Nordschleife сохраняет контур и характер высот, но сокращена до примерно
3,75 км. Три круга расчётный водитель проходит за 8–9,7 минуты; весь заезд
ограничен десятью минутами. Обе машины близки по темпу: Mustang свободнее
скользит, AMG точнее поворачивает и сильнее тормозит.

За каждым компьютером могут играть один или два человека. Для двоих экран
делится; удалённый одиночный игрок видит только свою камеру. В комнате до
шести машин. Выбор и готовность синхронизируются, состав закрепляется при
старте; потеря связи ставит игру на паузу, повторный вход сохраняет прогресс.

Обновите игру у всех участников: сетевой протокол 6 несовместим с прошлым
выпуском. Mac подписан Developer ID, нотариализация Apple пока отсутствует.
Физические геймпады и пара Windows ↔ Mac из разных сетей отдельно не проверены.

Скачать для Windows: `windows-x64-setup.exe` (установка) или
`windows-x64-portable.exe` (запуск без установки). Для Mac с чипом Apple —
`mac-arm64.dmg`, для Intel — `mac-x64.dmg`. HTML и `play.zip` работают офлайн;
для сетевой игры используйте приложение или сайт. Исходники, оригиналы
фотографий и геоданные сохранены в `source.zip`.
