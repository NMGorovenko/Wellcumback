# Исходные материалы

Все пользовательские оригиналы копируются без перекодирования, обрезки и изменения качества. Сохраняются в локальном `references/`, а производные игровые изображения — в `public/characters/`. Исходники кода находятся рядом в проекте и фиксируются в Git.

`references/manifest.json` содержит размеры файлов и SHA-256 для проверки целостности. `references/` исключён из Git и веб-публикации, но физически сохранён в проекте. При переносе проекта на другой компьютер копировать эту папку отдельно вместе с кодом.

- `references/characters/roma/` — 4 фотографии.
- `references/characters/yaroslav/` — 1 фотография.
- `references/characters/nikita/` — 3 фотографии.
- `references/vehicles/mustang/` — 2 фотографии красного Mustang для будущей истории.
- `references/stories/` — оригинальный скриншот рассказа про другую роту.

Номера на автомобиле и посторонние люди на исходниках не требуются для игрового ассета. По умолчанию в будущем ассете использовать вымышленный номер и только сам автомобиль.

Исключение первой версии: портрет Никиты временно использует копию исходного фото `public/characters/nikita-reference.jpg`, поскольку генератор отклонил другой его референс в формате MPO. Оригинал сохранён неизменным.
