# Проверка 0.9.0 — 13 сентября 2026

## Автоматические проверки

- 336/336 тестов проходят, TypeScript и oxlint проходят.
- Полный газ после 0,5 с даёт 10,85 м/с; после 0,9 с достигается предел 18 м/с. Четверть аналогового триггера остаётся медленной для парковки.
- Накопитель фиксированного шага больше не теряет такт из-за округления периода 144 Гц. После двух секунд симуляции значения времени и пути одинаковы при 30/60/144 Гц.
- Реальные маршруты к трём историям, остановка с намеренным E, проход обоих мостов в обе стороны и полный круг с ручником проходят без ударов. Прогрессивный газ устранил слишком широкое кружение вокруг конечной точки при постоянном ручнике.
- Геометрия обоих берегов и новый северный/южный фон помещаются в обзорную камеру. Новые крупные здания занимают прежние footprints, детали улиц проверяются на зазоры от дорог, воды, зданий и остановок.
- Окружение после объединения: 47 статических mesh-групп, 78 508 треугольников, 52 геометрии. Вдобавок к прежним набережным созданы 68 фонарей/деревьев. 180 обновлений сцены не добавляют геометрии, материалы или текстуры. Эти числа не заменяют аппаратное измерение FPS.

## Встроенный браузер

- Отдельная локальная вкладка: миникарта в правом нижнем углу, обе стороны реки и мосты читаются; нажатием открывается весь город.
- Выбрана старая квартира Ярика; после переключений «Весь город → Лица → За машиной» сохранились цель, расстояние и выделение миникарты.
- Обычная W, 550 мс: скорость 11,87 м/с, без столкновений; проверено плавное расширение обзора с разгоном. После проверки машина возвращена на дорогу.
- Осмотрены новые мосты, вокзал, театр, часовая башня, северный холм, фасады, фонари и скальный фон. Основная пользовательская сетевая вкладка не использовалась для тестового вождения.

## Приложения

- Собраны DMG/ZIP для Mac arm64 и x64, portable EXE и установщик для Windows x64. Они используют общий автономный renderer версии 0.9.0.
- На Mac arm64 прошли три настоящих запуска Electron: вождение и интерфейс; холодный перезапуск с сохранением; переезд с комиксами и паузой. Проверены раскрытие миникарты, возврат к камере за машиной, настоящие события клавиатуры, настройки, fullscreen с canvas на всю область окна и изоляция renderer.
- Первые попытки прервались из-за скрытого/неактивного окна в macOS Space. Одноразовое тестовое окно теперь показывается над другими пространствами; штатная обработка потери фокуса не отключалась. После исправления тестовой обвязки все три этапа завершились успешно.
- Физические контроллеры, Windows и Intel Mac не участвовали в аппаратной приёмке; имитация Gamepad API не считается проверкой настоящего DualSense.
