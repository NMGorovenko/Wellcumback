# Приёмка FRIENDSLOP 0.13.0

14 сентября 2026. Отдельные гонки, локальный split-screen и сетевые места.

## Проверки механики и связи

Фиксированный шаг физики проверен при разных частотах кадров. Последовательные
ворота исключают пропуски и обратный проезд. Проверены сохранение серии после
заноса, её потеря при ударе, столкновения двух машин, безопасный возврат после
последних ворот, завершение по лимиту без выдуманных финишей.

SQLite/сервер/настоящий room-client проверены вместе: атомарный старт при
одновременном входе гостя, сохранность неподтверждённых команд, недопустимые
машины, устаревшая готовность, независимый ввод 2 местных + удалённого,
короткий импульс второго игрока, пауза и восстановление прежнего attempt,
нейтрализация обоих контроллеров после переподключения.

Шесть расчётных прохождений Nordschleife зарегистрировали 46/46 ворот за три
круга, без сбросов и контактов. Разница темпа машин менее 1%; измеренное время
с отсчётом 8:06–9:41. Это сравнение одного контроллера на центральной траектории,
а не оценка мастерства человека или баланс соревнования по дрифту.
[Подробные замеры и воспроизведение](verification/race-balance-v0.13.md).

## Ограничения

Контур трассы основан на OSM, высоты — на DGM1 Rheinland-Pfalz. Полная геометрия
и исходные данные сохранены; игровая версия уменьшена до 18%, ветви Karussell
локально разведены. Покрытие, ширина, ограждения, деревья и здания приближённые;
это не копия лазерного сканирования. AMG и Mustang используют аркадную физику.

Новый ручной браузерный осмотр, субъективная оценка звука, физические геймпады,
Intel Mac и Windows в этой итерации не проверялись. Проверка реальной пары
Mac ↔ Windows из разных сетей остаётся отдельной задачей. Mac подписывается
Developer ID, нотариализации Apple нет.

## Сборки

Все **460 тестов**, TypeScript, Oxlint и production-сборка прошли.
Логи: `outputs/race-full-tests.log`, `race-typecheck.log`, `race-lint.log`,
`race-build.log`. Portable HTML содержит игровые ресурсы внутри файла.

Собраны Mac arm64/x64 ZIP и DMG, Windows x64 portable/setup и сервер.
Все четыре Mac-контейнера проверены после извлечения: версия и архитектура,
SHA-256, Developer ID, hardened runtime, подпись вспомогательного процесса,
совпадение игрового ASAR и соответствие исходникам. Нотариализации нет.

Готовый ARM64-клиент из подписанного ZIP прошёл запуск WebGL, изоляцию renderer,
управление поездкой, работу AudioContext и продвижение часов аудиоустройства.
Через интерфейс создана LAN-комната; отдельный гость подключился и получил
настоящий снимок города. Подписанный бандл после завершения не изменился.
Проверка использовала временный профиль; установленная игра не затронута.

Windows собран отдельно на Mac. Проверены вложенный PE x64, версия 0.13.0,
одинаковый ASAR в portable/setup, контрольные суммы runtime, renderer и helper.
Все 454 исходных файла сборки совпали с основным checkout. Временная сборка
использовала `preserveSymlinks` для локальной ссылки на зависимости; итоговый
сетевой модуль побайтово совпал с основным. Запуск на Windows не выполнялся.

Серверный пакет проверен в отдельном процессе: два WebSocket-клиента,
обновление SQLite, рестарт, переподключение с паузой и корректная остановка.

Отчёты: `outputs/mac-artifacts-v0130.json`, `signed-mac-smoke-v0130.log`,
`windows-verification-v0130.json`, `server-smoke-v0130.log`.
Сайт опубликован до версии 19 из коммита `be9f67c`; последующий коммит меняет
приёмочные документы. Исходники, оригинальные фотографии и геоданные входят
в source ZIP. Упаковка проверяет исходные фотографии и соответствие сборок;
файлы GitHub сверяются по SHA-256 перед открытием релиза.
